## States

Default → hover → disabled. Hover styling is built in via Tailwind; the disabled prop greys the button and blocks pointer events.

## Icon only

Set `iconOnly` to render a square button. Always pair with `aria-label` so screen readers announce the action.

## Props

| Prop        | Type                                  | Default     | Notes |
|-------------|---------------------------------------|-------------|-------|
| `variant`   | `'primary' \| 'outline' \| 'error'`   | `'primary'` | Visual style |
| `size`      | `'xs' \| 'sm' \| 'md' \| 'lg'`        | `'md'`      | Height: 28 / 32 / 36 / 40 |
| `iconOnly`  | `boolean`                             | `false`     | Square button — children should be the icon. Requires `aria-label`. |
| `loading`   | `boolean`                             | `false`     | Replaces leftIcon with spinner, sets `aria-busy`, disables clicks |
| `leftIcon`  | `ReactNode`                           | —           | Hidden from AT (`aria-hidden`) |
| `rightIcon` | `ReactNode`                           | —           | Ignored when `iconOnly` is true |
| `disabled`  | `boolean`                             | `false`     | Visually greyed, blocks pointer events |
| `children`  | `ReactNode`                           | —           | Label, or the icon when `iconOnly` is true |
| `type`      | `'button' \| 'submit' \| 'reset'`     | `'button'`  | Defaults to `'button'` to prevent accidental form submits |

Extends all native `<button>` HTMLAttributes.

## Accessibility

- Native `<button>` under the hood — keyboard, screen-reader, and form behavior comes for free.
- `iconOnly`: consumer must pass `aria-label`. Decorative icons inside `leftIcon` / `rightIcon` are `aria-hidden`.
- Loading: `aria-busy="true"` + disabled pointer events so repeated clicks are impossible.
- Focus ring: `:focus-visible` only — no ring on mouse click.

## Things to watch

- Loading state replaces `leftIcon` but keeps children visible. If you rely on the icon for meaning, your label should still stand alone.
- For form submits, remember to pass `type="submit"` — the component defaults to `type="button"`.
- `iconOnly` without `aria-label` is a hard accessibility bug. Lint rules will not catch this — code review will.
