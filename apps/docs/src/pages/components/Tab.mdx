## Composing a tab bar

`Tab` is the atom — compose into a horizontal list with parent-managed selected state. Wrap in `role="tablist"` for assistive tech.

<PreviewCard align="start">
  <TabBarDemo
    tabType="underline"
    items={[{ label: 'Overview' }, { label: 'Activity' }, { label: 'Settings' }]}
  />
</PreviewCard>

```tsx
const [active, setActive] = useState('Overview');
const tabs = ['Overview', 'Activity', 'Settings'];

<div role="tablist" className="flex items-center gap-2">
  {tabs.map((t) => (
    <Tab key={t} tabType="underline" active={t === active} onClick={() => setActive(t)}>
      {t}
    </Tab>
  ))}
</div>
```

## Props

| Prop | Type | Default | Notes |
|------|------|---------|-------|
| `tabType` | `'menu' \| 'underline' \| 'screen-nav' \| 'pill'` | `'underline'` | Visual style. |
| `active` | `boolean` | `false` | Marks the tab as currently selected. Sets `aria-current="true"`. |
| `disabled` | `boolean` | `false` | Disables clicks; greys out. |
| `icon` | `React.ReactNode` | — | Leading icon. Indigo-tinted on Menu/Active. |
| `trailingIcon` | `React.ReactNode` | — | Right-side icon (e.g. settings cog on Menu/Active). |
| `shortcut` | `string` | — | Keyboard shortcut letter chip (only renders for `tabType="screen-nav"`). |
| `children` | `React.ReactNode` | — | Tab label. |

Extends native `<button>` HTMLAttributes (omit overridden `type`).

## Accessibility

- Renders as native `<button type="button">` — keyboard activation (Enter/Space), focus management, and SR semantics come for free.
- `aria-current="true"` set on the active tab so assistive tech reports the selected state.
- Focus ring uses `:focus-visible` (no ring on mouse click) via the shared `border-focus` token.
- For keyboard tab navigation between Tabs, parent should handle `ArrowLeft` / `ArrowRight` if the group acts as a roving tablist (`role="tablist"`).

## Things to watch

- `Tab` is stateless — parent owns `active`. The component never auto-selects on click; wire `onClick` to your own state.
- `icon` indigo tint is Menu/Active only. Other types pass `icon` through with the muted text color — that's by design.
- `shortcut` prop only renders for `tabType="screen-nav"` — passing it to other types is silently ignored.
- Underline bar is purely decorative; if the active label needs to wrap, the bar still centers on the first line.
