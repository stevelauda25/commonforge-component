## Usage

  <UsageExample />

```tsx
import { Radio } from 'pod-test-ui';

const [value, setValue] = useState('email');

<Radio
  name="contact"
  value="email"
  checked={value === 'email'}
  onCheckedChange={(checked) => checked && setValue('email')}

/>
```

### Group — controlled

Radios share state through the `name` attribute and a single state value. Always pass `checked` and update it from `onCheckedChange`.

<PreviewCard>
  <ControlledGroup />
</PreviewCard>

```tsx
function ContactPreference() {
  const [value, setValue] = useState('email');
  return (
    <div className="flex flex-col gap-3">
      {['email', 'sms', 'push'].map((option) => (
        <Radio
          key={option}
          name="contact"
          value={option}
          checked={value === option}
          onCheckedChange={(checked) => checked && setValue(option)}
          label={option.toUpperCase()}
        />
      ))}
    </div>
  );
}
```

export function UsageExample() {
  const [value, setValue] = useState('email');
  return (
    <div className="flex flex-col gap-3">
      <Radio
        name="usage-demo"
        value="email"
        checked={value === 'email'}
        onCheckedChange={(checked) => checked && setValue('email')}
        label="Email"
      />
      <Radio
        name="usage-demo"
        value="sms"
        checked={value === 'sms'}
        onCheckedChange={(checked) => checked && setValue('sms')}
        label="SMS"
      />
    </div>
  );
}

export function ControlledGroup() {
  const [value, setValue] = useState('email');
  return (
    <div className="flex flex-col gap-3">
      {['email', 'sms', 'push'].map((option) => (
        <Radio
          key={option}
          name="group-demo"
          value={option}
          checked={value === option}
          onCheckedChange={(checked) => checked && setValue(option)}
          label={option === 'email' ? 'Email' : option === 'sms' ? 'SMS' : 'Push notification'}
          description={value === option ? 'Selected' : undefined}
        />
      ))}
    </div>
  );
}

## API Reference

| Prop              | Type                          | Default | Notes |
|-------------------|-------------------------------|---------|-------|
| `size`            | `'sm' \| 'md'`                | `'sm'`  | `sm` = 16px indicator, `md` = 20px. |
| `checked`         | `boolean`                     | —       | Controlled state. Omit + use `defaultChecked` for uncontrolled. |
| `onCheckedChange` | `(checked: boolean) => void`  | —       | Fires on user toggle. Pair with sibling radios via `name`. |
| `label`           | `ReactNode`                   | —       | Renders as `<label>` linked via `htmlFor`. |
| `description`     | `ReactNode`                   | —       | Help text under the label. Linked via `aria-describedby`. |
| `disabled`        | `boolean`                     | `false` | Dims the control and blocks pointer events. |
| `name`            | `string`                      | —       | Required for grouping native radios. |
| `id`              | `string`                      | auto    | Auto-generated via `useId` when omitted. |

Extends all native `<input type="radio">` HTMLAttributes (minus `type`, `size`, `onChange`).

## Accessibility

### Grouping

Native `<input type="radio">` — sibling radios with the same `name` form a group. Arrow keys move selection between them; Tab moves focus to the next focusable element.

### Label association

When `label` is provided, the component generates an `id` (via `useId`) and renders the visible label tied to the `<input>`. Pass your own `id` to override. For label-less usage, supply `aria-label` directly.

### Keyboard

- **Space** — selects the focused radio (no-op if already selected).
- **Arrow keys** — move selection within the group.
- **Tab** / **Shift+Tab** — move focus between groups.
