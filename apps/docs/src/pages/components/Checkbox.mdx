## States

Off, on, and indeterminate. Use `'indeterminate'` for "some children selected" parents in tree-style multi-selects.

## Props

| Prop              | Type                                | Default | Notes |
|-------------------|-------------------------------------|---------|-------|
| `checked`         | `boolean \| 'indeterminate'`        | —       | Required. `'indeterminate'` renders the minus glyph. |
| `onCheckedChange` | `(checked: boolean) => void`        | —       | Fired on user toggle. Indeterminate always transitions to `true`. |
| `label`           | `ReactNode`                         | —       | Renders as a `<label>` linked via `htmlFor`. |
| `description`     | `ReactNode`                         | —       | Hidden when `error` is set. Linked via `aria-describedby`. |
| `error`           | `string`                            | —       | Sets `aria-invalid` and replaces the description. |
| `disabled`        | `boolean`                           | `false` | Greys out and blocks pointer events. |
| `id`              | `string`                            | auto    | Auto-generated when omitted; needed when wiring custom labels. |

Extends all native `<input type="checkbox">` HTMLAttributes (minus `type`, `checked`, `onChange`, `size`).

## Accessibility

- Native `<input type="checkbox">` — keyboard, screen-reader, and form participation come for free.
- `indeterminate` is set via the DOM property (the attribute doesn't exist) — handled internally via a `useEffect`.
- `error` sets `aria-invalid="true"` and is announced via `aria-describedby`.
- Always pair with a `label` (visible) or `aria-label` (when intentionally label-less).

## Things to watch

- `onCheckedChange` receives a `boolean`. The `'indeterminate'` value is display-only; user clicks always commit to `true` or `false`.
- The component is fully controlled — there's no internal state. Always pass `checked` and update it from `onCheckedChange`.
- For "select all" parent rows, derive `checked` from children: `all → true`, `some → 'indeterminate'`, `none → false`.
