## Filterable

With `filterable`, the field becomes an editable input on the same field recipe: clicking focuses it, typing opens the list and live-filters the options by a case-insensitive substring match on the label. Arrow keys move the active option, Enter selects it (the field text becomes the option's label), and Escape first clears the query, then closes the list. When nothing matches, the list renders a single "No results" row.

<PreviewCard align="start">
  <div className="w-full max-w-sm space-y-3">
    <Dropdown filterable options={projects} placeholder="Type to filter projects" />
    <Dropdown filterable size="sm" options={projects} placeholder="Type to filter projects" />
  </div>
</PreviewCard>

## Filterable — pinned open

Pinned open with the `open` prop. The filterable field keeps the same focus ring, chevron rotation, size-matched ListBase rows, and the trailing check on the selected option; accessibility switches to the ARIA combobox pattern (`role="combobox"`, `aria-expanded`, `aria-controls`, `aria-activedescendant`).
