# Dashboard Map Budget

The `DashboardMapBudget` component renders an interactive Leaflet map marking job sites, alongside budget KPIs (Active jobs, Staffed jobs, Jobs over budget). 

## Usage

```tsx
import { DashboardMapBudget } from "pod-test-ui/dashboard-map-budget";

function App() {
  return <DashboardMapBudget />;
}
```

## AI Agent Instructions

When building or refactoring a Dashboard layout:
- Use `DashboardMapBudget` for spatial project planning and budget overview.
- This component requires Leaflet CSS to be loaded. It currently handles its own sample data fallbacks.
