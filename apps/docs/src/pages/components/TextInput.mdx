## Examples

### Variants

Five semantic variants — each sets the HTML `type`, default adornments, and placeholder. `default` is bare; `password` includes a show/hide toggle; `date` uses native `type="date"`; `phone` and `amount` render visual dropdown stubs for country / currency (real selection lands when the Select primitive ships).

<PreviewCard>
  <div className="flex flex-col gap-4 w-[300px]">
    <TextInput variant="default" label="Default" placeholder="Placeholder text..." />
    <TextInput variant="password" label="Password" />
    <TextInput variant="phone" label="Phone Number" />
    <TextInput variant="date" label="Date" />
    <TextInput variant="amount" label="Amount" />
  </div>
</PreviewCard>

```tsx
<TextInput variant="default"  label="Default"      placeholder="Placeholder text..." />
<TextInput variant="password" label="Password" />
<TextInput variant="phone"    label="Phone Number" />
<TextInput variant="date"     label="Date" />
<TextInput variant="amount"   label="Amount" />
```

Pass `leftIcon` or `rightIcon` to override the variant's default adornments. Pass `placeholder` to override the default placeholder.

## API Reference

| Prop | Type | Default | Notes |
|------|------|---------|-------|
| `label` | `string` | — | Visible label text above the input. |
| `required` | `boolean` | `false` | Shows a red asterisk next to the label. Also sets the native `required` attribute. |
| `sublabel` | `string` | — | Muted text after the label, e.g. `"(Optional)"`. |
| `labelInfo` | `boolean` | `false` | Renders a small info icon next to the label. |
| `hint` | `string` | — | Help text below the input. Hidden when `error` is set. |
| `error` | `string` | — | Error message — replaces `hint`, applies destructive border, sets `aria-invalid`. |
| `leftIcon` | `ReactNode` | — | Icon slot before the input text. |
| `rightIcon` | `ReactNode` | — | Icon slot after the input text. |
| `size` | `'sm' \| 'md'` | `'md'` | Input padding size. `md` = 12px, `sm` = 8px. |
| `variant` | `'default' \| 'password' \| 'phone' \| 'date' \| 'amount'` | `'default'` | Semantic variant — sets HTML type + default adornments + placeholder. |
| `type` | `string` | `'text'` | HTML input type. Variant takes precedence for `password`/`phone`/`date`/`amount`. |
| `disabled` | `boolean` | `false` | Disables the input and dims the container. |

Extends all native `<input>` HTMLAttributes (minus `size` and `type` which are overridden).

## Accessibility

### Label association

When `label` is provided, the component generates an `id` (via `useId`) and renders the visible label tied to the `<input>`. Pass your own `id` to override.

### Error association

`error` sets `aria-invalid="true"` on the input and links the error message via `aria-describedby`. When no error is present, `hint` is linked instead. Both cannot be active at once — `error` takes precedence.

### Decorative icons

`leftIcon`, `rightIcon`, and the `labelInfo` icon are `aria-hidden`. If an icon conveys meaning (e.g. a status indicator), wrap it and add your own `aria-label` on the parent.

### Focus

The container uses `focus-within` so clicking adjacent icons still activates the focus ring on the visible element.
