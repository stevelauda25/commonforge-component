# Dashboard Skills Insights

The `DashboardSkillsInsights` component renders a summary of worker skills, showing KPIs like average skill level and a breakdown of Trade vs. Professional skills.

## Usage

```tsx
import { DashboardSkillsInsights } from "pod-test-ui/dashboard-skills-insights";

function App() {
  return <DashboardSkillsInsights />;
}
```
