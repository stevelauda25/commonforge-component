## Removable (interactive)

Pass `onClose` to make the × a real button that fires on click. Use this for filter chips or selected-tag UIs where the consumer wants to dismiss.

<PreviewCard align="start">
  <div className="flex flex-wrap items-center gap-2">
    <Badge color="indigo" onClose={() => alert('Removed')}>FILTER</Badge>
    <Badge color="sky" onClose={() => alert('Removed')}>TAG</Badge>
  </div>
</PreviewCard>

## Props

| Prop | Type | Default | Notes |
|------|------|---------|-------|
| `color` | `'green' \| 'lime' \| 'orange' \| 'yellow' \| 'red' \| 'purple' \| 'indigo' \| 'sky' \| 'blue' \| 'soft-gray' \| 'dark-gray'` | `'green'` | Tinted color treatment. |
| `closable` | `boolean` | `true` | Show the trailing × icon. Decorative unless `onClose` is also passed. |
| `onClose` | `() => void` | — | When provided, × renders as a real `<button>` and calls this on click. |
| `children` | `React.ReactNode` | — | The label text. Convention: uppercase, short. |

Extends native `<span>` HTMLAttributes (except `color`, which is the variant prop).

## Accessibility

- Renders as a `<span>` (presentation-level) by default — when `onClose` is set, the × becomes an interactive `<button>` with `aria-label="Remove"`.
- × icon has `aria-hidden="true"` in the decorative-only path so screen readers don't announce the close glyph for non-removable badges.
- Tag dot has `aria-hidden="true"` — purely visual signal, not part of the label.
- Label uses IBM Plex Mono Medium — make sure the font is loaded by your app shell. Falls back to `ui-monospace` if not.
- If removable badges participate in a list (e.g. filter chips), wrap them in a parent with `role="list"` and give each badge `role="listitem"` for clearer SR semantics.

## Things to watch

- The Dark Gray variant adds a 1px border (Figma `stroke/strong`) — other variants are border-less. If you wrap badges in a container that already has a border, this one may visually double up.
- The color tag (3×10px dot) is fixed-width — long labels do NOT push the dot wider. Truncate label client-side if you need a hard width cap.
- Label uses uppercase per Figma convention; the component does NOT auto-uppercase. Pass `STATUS` not `Status` if you want the canonical look.
- `closable={true}` + no `onClose` renders a decorative × — clicking it does nothing. Mostly useful for visual matches in static contexts (lists, search results). Don't use this in filter UIs; always wire `onClose`.
