## Small size

`size="sm"` renders a compact single-line field (32px height, 8px horizontal padding, 12px/16px text). The size applies to single-line fields only — the multiline TextArea has no size variant.

<PreviewCard align="start">
  <div className="w-[460px]">
    <TextField
      size="sm"
      label="Label"
      required
      placeholder="Enter your full name"
      hint="This is a hint text to help user."
    />
  </div>
</PreviewCard>
