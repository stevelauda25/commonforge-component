### Removable — filter chip pattern

Pass an `onRemove` handler to render a trailing × button. The chip itself can stay clickable (toggle) while × dismisses it independently. Clicks on × don't bubble.

<PreviewCard>
  <RemovableExample />
</PreviewCard>

```tsx
const [tags, setTags] = useState(['Design', 'Engineering', 'Marketing']);

<div className="flex flex-wrap gap-2">
  {tags.map((tag) => (
    <Tag
      key={tag}
      leadingIcon={<Hash className="h-3 w-3" />}
      onRemove={() => setTags((prev) => prev.filter((t) => t !== tag))}
    >
      {tag}
    </Tag>
  ))}
</div>
```

export function UsageExample() {
  return (
    <div className="flex flex-wrap gap-2">
      <Tag>Featured</Tag>
      <Tag color="gray">Draft</Tag>
      <Tag leadingIcon={<Hash className="h-3 w-3" />} onRemove={() => {}}>topic</Tag>
    </div>
  );
}

export function RemovableExample() {
  const [tags, setTags] = useState(['Design', 'Engineering', 'Marketing']);
  return (
    <div className="flex min-h-[28px] flex-wrap gap-2">
      {tags.length === 0 ? (
        <button
          type="button"
          onClick={() => setTags(['Design', 'Engineering', 'Marketing'])}
          className="text-xs text-subtle underline underline-offset-2 hover:text-default"
        >
          Reset
        </button>
      ) : (
        tags.map((tag) => (
          <Tag
            key={tag}
            leadingIcon={<Hash className="h-3 w-3" />}
            onRemove={() => setTags((prev) => prev.filter((t) => t !== tag))}
          >
            {tag}
          </Tag>
        ))
      )}
    </div>
  );
}

## API Reference

| Prop          | Type                                            | Default      | Notes |
|---------------|-------------------------------------------------|--------------|-------|
| `color`       | `'default' \| 'gray'`                           | `'default'`  | Visual treatment. |
| `active`      | `boolean`                                       | `false`      | Pressed/selected look. Drives `aria-pressed` when `onClick` is set. |
| `disabled`    | `boolean`                                       | `false`      | Dims the chip, blocks `onClick` and `onRemove`. |
| `leadingIcon` | `ReactNode`                                     | —            | Icon before the label. Sizes naturally to 14×14. |
| `onClick`     | `(e: MouseEvent) => void`                       | —            | When set, the chip becomes role=button and keyboard-activatable. |
| `onRemove`    | `(e: MouseEvent) => void`                       | —            | When set, renders trailing × button. Click doesn't bubble to chip `onClick`. |
| `removeLabel` | `string`                                        | `'Remove'`   | `aria-label` on the × button. |
| `children`    | `ReactNode`                                     | —            | The label content. |

Extends `<span>` HTMLAttributes (minus `onClick`, which is typed for activatable semantics).

## Accessibility

### Role

When `onClick` is provided, the chip becomes `role="button"` with `tabIndex={0}` and responds to Space/Enter. Without `onClick`, it's a plain `<span>` (no role, not focusable).

### Removable button

The × is always a real `<button>` with its own `aria-label` (default `"Remove"`). It stops click propagation so dismissing doesn't also toggle the chip. Customize the label via `removeLabel` for screen-reader clarity (e.g. `"Remove Design tag"`).

### Disabled

`aria-disabled="true"` is set, click handlers are no-ops, and the cursor changes to `not-allowed`. The chip stays in the tab order — set `tabIndex={-1}` manually if you want it skipped.

### Motion

This component does not animate dismissal by itself. For the polished "fade + scale + collapse-width" exit motion documented in [Motion](/foundations/motion), wrap with the pattern from `BadgeRemovableDemo` (see source).
