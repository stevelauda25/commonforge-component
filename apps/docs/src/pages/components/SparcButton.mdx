## Sizes

All variants share the same four sizes. The second row shows inverse at every
size on the default light surface — inverse has the full state matrix (hover
dims the label to white/80, active to white/60) and its border is 1px at
lg/md, 0.5px at sm/xs.

container shadow, and dimmed labels per the Figma spec.

## Loading

Loading adopts the disabled styling of each variant — flat fill, reduced (or
no) container shadow, dimmed label — and swaps the leading icon for a spinner
tinted to match the label. The button is non-interactive while loading. First
row: all six variants at lg. Second row: primary across all four sizes.
