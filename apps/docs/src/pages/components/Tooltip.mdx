Wraps a single focusable child via Radix Tooltip primitives. Keyboard focus, Escape to dismiss, and screen-reader semantics come from Radix — we only style.

## Examples

The Figma spec — bold title on top of a muted body row. Use for short headings ("Keyboard shortcut") with a longer explanation.

### Semantic variants

`info`, `warning`, and `error` add a colored background and leading icon — use sparingly, for product affordances like inline validation hints or risky-action confirmations.

### Controlled

Pass `open` + `onOpenChange` for programmatic control — useful in onboarding flows or when pairing with custom triggers.

```tsx
const [open, setOpen] = useState(false);

<Tooltip open={open} onOpenChange={setOpen} content="Click me!">
  <Button>Try it</Button>
</Tooltip>
```

## API Reference

| Prop             | Type                                                   | Default     | Notes |
|------------------|--------------------------------------------------------|-------------|-------|
| `title`          | `ReactNode`                                            | —           | Bold title row. Omit for single-row body-only tooltips. |
| `content`        | `ReactNode`                                            | —           | Body row. Required. |
| `children`       | `ReactElement`                                         | —           | The trigger. Must be a single focusable element (button, anchor). |
| `variant`        | `'default' \| 'info' \| 'warning' \| 'error'`          | `'default'` | Semantic color. Non-default variants render an inline icon. |
| `side`           | `'top' \| 'right' \| 'bottom' \| 'left'`               | `'top'`     | Position relative to the trigger. |
| `align`          | `'start' \| 'center' \| 'end'`                         | `'center'`  | Shift along the trigger edge. |
| `sideOffset`     | `number`                                               | `6`         | Gap (px) between trigger and tooltip. |
| `delayDuration`  | `number`                                               | `200`       | ms before opening on hover. Set `0` for instant. |
| `defaultOpen`    | `boolean`                                              | —           | Uncontrolled initial open state. |
| `open`           | `boolean`                                              | —           | Controlled open state (pair with `onOpenChange`). |
| `onOpenChange`   | `(open: boolean) => void`                              | —           | Fires when Radix opens or closes. |

## Accessibility

### Keyboard

Tooltips open on **hover** and **keyboard focus**, and close on **mouseleave**, **blur**, or **Escape**. The trigger must be focusable — wrap a `<button>`, `<a>`, or any element with `tabIndex={0}`.

### Screen readers

Radix exposes the tooltip content via `aria-describedby` on the trigger when open. Don't put critical info in a tooltip — use a permanent label or aria-label for anything required to use the control.

### Disabled triggers

Native disabled `<button>` elements don't fire pointer events, so tooltips won't open. If you need a tooltip on a disabled control, wrap it in a `<span tabIndex={0}>` (or use `aria-disabled` instead of native `disabled`) so focus and hover still reach it.

### Motion

Open/close animations honor `prefers-reduced-motion`. Defaults to 280ms fade + zoom — same family as the rest of POD's [Motion](/foundations/motion) tokens.
