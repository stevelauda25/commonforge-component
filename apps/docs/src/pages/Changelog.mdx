## v0.1.0 — 2026-04-27

- Initial sprint scaffold: tokens (`@pod/tokens`), components (`@pod/ui`), playground (`apps/playground`), docs site (`apps/docs`).
- Components: Button (5 variants × 3 sizes), Checkbox (incl. indeterminate), Search Input (clearable), Tooltip (4 variants).
- Light + dark mode via semantic CSS variables.
- Docs site with kumo-style component grid and asto-style sidebar IA.
