## 2026-07-21 — SPARC token + atom collection

### Foundations

- Color, typography, spacing, radius, and elevation tokens collected from the SPARC apps (carltonLaborPlanning + commonforge-sparc-ui). This collection is this repo's token source; see the Foundations pages for the full scales and decision log.

### Components

- 15 atoms documented from the SPARC apps: Button, Badge, Checkbox, Switch, Tag, Input, Text Area, Radio, Segmented Button, Slider, Loading Spinner, Avatar, Separator, List Base, Tooltip.
