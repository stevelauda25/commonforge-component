## Token shadows

Three token shadows: `elev-1` for cards, `elev-2` for raised cards, `pop` for
modals. All use the warm charcoal `rgba(32,27,24,…)` base.

<SparcShadowGrid />

| Token | Use |
|---|---|
| `shadow-elev-1` | cards |
| `shadow-elev-2` | raised cards |
| `shadow-pop` | modals |

## Shared shadow recipes (not yet tokens)

Four multi-layer shadow recipes live in component code, identical in both SPARC
apps — candidates to promote into tokens:

| Recipe | Used by |
|---|---|
| Button shadow (6 layers incl. inset highlights) | button, segmented pill, date-picker Apply |
| Card shadow "003" (5 layers) | kpi-card, dashboard panels, job cards |
| Popover/menu shadow (3 layers) | dropdowns, menus, date-picker card |
| Chart tooltip shadow (6 layers) | chart-tooltip |
