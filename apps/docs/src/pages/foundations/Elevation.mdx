## Tokens

| Token         | Class       | Use case |
|---------------|-------------|----------|
| `--shadow-sm` | `shadow-sm` | hairline lift; thin separator effect |
| `--shadow-md` | `shadow-md` | cards, popovers, dropdowns |
| `--shadow-lg` | `shadow-lg` | modals, drawers — high-lift surfaces |

## Brand glow

POD's primary button uses two extra brand-tinted shadows:

| Token                          | Class                   | Where it's used |
|--------------------------------|-------------------------|-----------------|
| `--shadow-glow-accent-inset`   | `shadow-glow-accent-inset` | inset top-edge highlight on `<Button variant="primary">` |
| `--shadow-glow-accent-text`    | (CSS-only)              | text-shadow halo on the same button |

Switch the theme — the shadow tokens scale up in dark mode for legibility on the dark canvas.
