## Token shadows

Six token shadows: three surface elevations (`elev-1`, `elev-2`, `pop`) using the
warm charcoal `rgba(32,27,24,…)` base, and three component shadows registered
2026-07-21 (`button`, `frame`, `card`).

<SparcShadowGrid />

| Token | Use |
|---|---|
| `shadow-elev-1` | cards |
| `shadow-elev-2` | raised cards |
| `shadow-pop` | modals |
| `shadow-button` | button, segmented pill, date-picker Apply (6 layers incl. inset highlights) |
| `shadow-frame` | dashboard frame surface — the #F7F7F7 container (3 layers + inset hairlines) |
| `shadow-card` | white cards/panels inside the frame — kpi-card, dashboard panels, job cards (5 layers) |
