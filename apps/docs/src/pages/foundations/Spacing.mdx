## Scale samples

The visible bars below correspond to Tailwind classes `w-1`, `w-2`, … `w-12`. Each unit = 4px.

## Common usage

| Class         | Pixels | Use case |
|---------------|--------|----------|
| `gap-1`       | 4      | tight icon ↔ label gap |
| `gap-2`       | 8      | default form-control gap |
| `gap-3`       | 12     | between buttons |
| `gap-4`       | 16     | between sections |
| `p-3`         | 12     | card padding (compact) |
| `p-4`         | 16     | card padding (default) |
| `p-6`         | 24     | page section padding |
| `px-8`        | 32     | wide horizontal padding |

## Usage

```tsx
<div className="flex items-center gap-2 p-4">
  <Icon className="h-4 w-4" />
  <span>Label</span>
</div>
```
