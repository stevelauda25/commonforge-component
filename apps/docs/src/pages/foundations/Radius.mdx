## Usage

Reach for `rounded-md` for standard cards/inputs, `rounded-lg` for buttons,
`rounded-full` for pills/avatars. Avoid hardcoded `rounded-[6px]` — pick the
nearest scale step instead.

```tsx
// ✓ Standard card
<div className="rounded-lg border border-border-default bg-surface p-4">
  Card content
</div>

// ✓ Pill / avatar
<span className="rounded-full bg-accent-subtle px-3 py-1 text-xs">label</span>

// ✗ Don't hardcode
<div className="rounded-[7px]">…</div>   // pick rounded-sm or rounded-md
```

## Source of truth

The values live in [`packages/tokens/src/theme.css`](https://github.com/) (under `/* ── Radius ── */`)
and are exposed via [`packages/tokens/src/tailwind-preset.ts`](https://github.com/) under `borderRadius`.
When syncing from Figma via `/sync-figma foundation-radius`, those two files
update — and this page picks them up automatically at runtime.
