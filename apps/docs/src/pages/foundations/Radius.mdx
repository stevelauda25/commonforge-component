## Scale

Nine steps, 0px → 9999px. **`radius-xs` (4px) was added on 2026-07-21** (decision 5)
for badges, tags, and day cells; the same review round later extended the scale
with **`none` (0px)** for sharp edges, **`2xs` (2px)** for hairline rounding on tiny
controls, **`10` (10px)** between md and lg, and **`full` (9999px)** for pills and
circles. Sample boxes below are filled with the collected crimson-500.

<SparcRadiusGrid />

| Token | Value | Typical use |
|---|---|---|
| `radius-none` | 0px | sharp edges — tables, dividers, full-bleed surfaces |
| `radius-2xs` | 2px | hairline rounding on tiny controls |
| `radius-xs` | 4px | badges, tags, day cells |
| `radius-sm` | 6px | buttons, inputs, cards (default component radius) |
| `radius-md` | 8px | compact KPI cards |
| `radius-10` | 10px | medium panels, between md and lg |
| `radius-lg` | 12px | toasts, tooltips |
| `radius-xl` | 16px | large surfaces |
| `radius-full` | 9999px | pills, avatars, circles |

## One-offs outside the scale

`rounded-[3px]` (checkbox small, legend chip) and `rounded-[5px]` (drop-zone
inner, checkbox large) remain as acceptable component-level values — they are
used in code but not promoted to tokens.
