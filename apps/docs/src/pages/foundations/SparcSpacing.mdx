## Spacing scale

SPARC defines no custom spacing tokens — both apps use Tailwind's default
4px-based scale. This is that scale:

<SparcSpacingScale />

## The rem sizing model

Component dimensions (panel heights, input heights, icon sizes) are authored in
rem against the fixed **16px root font-size — "THE ONE KNOB"** — so the whole UI
scales proportionally from that single value. See
[SPARC Typography (staging)](/foundations/sparc-typography) for the type tokens
that share this model.

## Fixed component dimensions

Fixed dimensions (e.g. panel heights, sidebar width `15rem`) are not tokens —
they are documented per-component in the collection's component inventories. If
the design system wants a spacing scale later, that is a new decision, not an
extraction.
