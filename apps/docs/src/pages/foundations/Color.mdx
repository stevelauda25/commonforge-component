## Light vs dark

Switch the theme toggle in the topbar — every swatch above re-paints from the `.dark` overrides defined in `pod-test-tokens/theme.css`. Components consume the same Tailwind class names; the variables swap underneath.

## Usage

```tsx
<div className="bg-surface text-default border border-default">
  Token-driven container
</div>
```

Never embed hex values in components or MDX. If you need a color that isn't in the semantic set, propose a new token rather than reaching for a primitive.
