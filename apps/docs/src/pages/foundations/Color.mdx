## Palette ramps

Six ramps extracted value-for-value from the running apps. `neutral` is the warm
brand ramp (cream/charcoal), `crimson` is the brand/action ramp (500 `#C0180C` =
primary buttons), and `red` is deliberately distinct from crimson for error states.
The cool `gray` ramp comes from Figma Primitives (18 shades incl. the 75/150/250/350/975
half-steps) — only the 3001 app had it tokenized.

Notes from the collection doc:

- `secondary` is a **cool gray inside a warm system** — intentional, matches Figma.
- `border-hairline` exists, but most components actually use `border-black/10` at
  0.5px instead of the hairline token.
- `muted-foreground` / `subtle-foreground` are rarely used in components so far.

## Decisions applied 2026-07-21

1. **`--primary: #000000` → renamed to `--text-primary`** — it is a text color.
   The black was always the primary *text* color (~70 usages of the `text-primary`
   class), not the action color. Actions are crimson-500. The `--color-primary`
   theme mapping now points at `--text-primary`, so existing `text-primary`
   classes keep working.
2. **`--danger-foreground: #9C1122` → removed**, replaced with
   `rgba(255, 255, 255, 0.95)` (near-white alpha). The token is currently unused
   in app code, so this is a safe default for future danger buttons.
3. `primary-hover` (`#98150B`, crimson-600) was **kept** — it is the text hover
   state (`hover:text-primary-hover` in JobCard/JobCardV2).
4. `primary-foreground` (`#FFFFFF`) was **kept** — text on dark/primary surfaces
   (used by dashboard widgets).
