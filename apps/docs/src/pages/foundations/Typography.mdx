## Font family

POD uses **Inter** with `cv11` and `ss01` font features enabled. Falls back to system fonts.

<PreviewCard>
  <p className="text-2xl font-semibold">The quick brown fox jumps over the lazy dog</p>
</PreviewCard>

## Size scale

| Token  | Size      | Line height | Sample |
|--------|-----------|-------------|--------|
| `xs`   | 12px      | 16px        | <span className="text-xs">Aa Caption</span> |
| `sm`   | 13px      | 18px        | <span className="text-sm">Aa Dense table cell</span> |
| `base` | 14px      | 20px        | <span className="text-base">Aa Body default</span> |
| `md`   | 15px      | 22px        | <span className="text-md">Aa Body large</span> |
| `lg`   | 16px      | 24px        | <span className="text-lg">Aa Lead</span> |
| `xl`   | 18px      | 26px        | <span className="text-xl">Aa Section heading</span> |
| `2xl`  | 20px      | 28px        | <span className="text-2xl">Aa Page heading</span> |
| `3xl`  | 24px      | 32px        | <span className="text-3xl">Aa Display</span> |

## Weights

| Class              | Weight |
|--------------------|--------|
| `font-normal`      | 400    |
| `font-medium`      | 500    |
| `font-semibold`    | 600    |
| `font-bold`        | 700    |

## Usage

```tsx
<h1 className="text-3xl font-semibold">Page heading</h1>
<p className="text-base text-text-secondary">Body copy</p>
<span className="text-xs text-text-muted">Helper</span>
```
