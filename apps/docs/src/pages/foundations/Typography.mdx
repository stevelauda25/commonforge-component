## Font family

SPARC uses **Geist** with Inter and system fallbacks.

<SparcFontPreview />

**No mono token is shipped by decision** (2026-07-21): neither Geist Mono nor
Space Mono. Mono usages (code snippets, job numbers, JSON logs) fall back to the
platform monospace stack via Tailwind's default `font-mono`, which needs no token.

## Size scale

Seven sizes in the collected scale (`text-3xs` → `text-body-lg`), of which three
— `text-xs`, `text-body`, `text-body-lg` — equal Tailwind stock values and are
marked as stock context rows. The collected line-heights **override** Tailwind's
stock `leading-tight` / `leading-snug`.

## Weights

<SparcWeights />

These are Tailwind stock classes as used across the SPARC components
(`font-medium` 500 is the workhorse); they are documented here, not yet tokens.

## Root font-size — "THE ONE KNOB"

Root font-size is fixed at **16px**. All component sizing is authored in rem
against it, so the whole UI scales from that single value.

## Source of truth

Values on this page come from `apps/docs/src/data/sparc-foundation.json`, copied
unchanged from the original collection (`design-system-testing-abdillah/foundation/tokens.json`,
